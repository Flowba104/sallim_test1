## 3. 긴 설명 (Full Description)

```text
"이건 재활용일까, 일반쓰레기일까? 우리 동네에는 무슨 요일에 내놓아야 하지?"
헷갈리는 분리배출, 이제 SaLLiM(살림)으로 하나씩 가볍게 확인해 보세요.

SaLLiM은 버릴 물건을 카메라로 찍거나 이름으로 검색하면, 분리배출 순서부터 우리 동네 배출 요일·시간까지 한 장의 안내 카드로 깔끔하게 정리해 드리는 생활 안내 앱입니다.

■ 주요 기능

1. 찍으면 바로 보이는 분리배출 순서
• 품목 이름을 몰라도 물건을 찍으면 어떤 카테고리로 버려야 하는지 알려 드려요.
• 긴 줄글이나 복잡한 챗봇 말풍선 대신, '비우고 → 헹구고 → 분리하는' 단계별 체크리스트로 한눈에 볼 수 있어요.
• 사진이 분명하지 않을 때는 억지로 단정하지 않고 솔직하게 알려 드려요.

2. 헷갈리는 상태는 '예 / 아니오'로 한 번 더 확인
• 라벨이 붙어 있는지, 내용물이 남았는지, 음식물·기름이 묻었는지, 코팅된 종이인지에 따라 버리는 방법이 달라져요.
• 사진만으로 알기 어려운 상태는 간단한 '예 / 아니오' 버튼 한 번으로 내 물건 상태에 꼭 맞는 배출법을 확인할 수 있어요.

3. 사진이 없어도 이름으로 간편하게 검색
• 투명 페트병, 배달 용기, 종이컵, 택배 상자, 컵라면 용기, 깨진 유리, 부탄가스, 폐건전지 등 자주 묻는 20가지 추천 품목 칩을 눌러 빠르게 찾아볼 수 있어요.

4. 우리 동네 배출 요일·시간과 오늘의 살림 안내장
• 홈 화면에서 오늘 우리 동네에 내놓을 수 있는 품목과 배출 시간을 바로 확인해요.
• 주간 요일표를 눌러 요일별 배출 가능 품목과 동네 전용 수거함(폐건전지·폐형광등·폐식용유·폐의약품·의류수거함 등) 안내를 함께 볼 수 있어요.
• 현재 서울특별시 관악구 기준 데이터를 지원하며, 지원 동네는 차례대로 넓혀 갈 예정이에요.

5. 믿을 수 있는 공식 출처와 기준일 표시
• AI가 배출 방법을 임의로 지어내지 않고, 기후에너지환경부 분리배출 지침과 지자체 공식 안내를 바탕으로 검증된 정보만 조립해 보여 드려요.
• 모든 결과 카드와 일정 안내 아래에서 실제 법령·지자체 출처 링크와 자료 기준일을 직접 확인할 수 있어요.

6. 회원가입·위치 권한 없이 가볍고 안전하게
• 로그인이나 상세 주소 입력, GPS 위치 권한 없이 사는 동네만 선택하면 바로 시작할 수 있어요.
• 촬영한 사진은 품목 확인에만 일시적으로 쓰이며 서버에 저장하지 않아요. 확인을 위해 AI 분석 서비스로 전송될 수 있어요.

■ 이용 시 유의사항
• 같은 구 안에서도 동이나 공동주택(아파트·오피스텔) 단지, 가로변 구역에 따라 세부 배출 요일과 시간이 다를 수 있어요. 단지 내 관리사무소 안내문이나 관할 구청 공지를 함께 확인해 주세요.
```

## 5. 개인정보처리방침 초안 (서버 실제 동작 확인 반영)

> **작성 근거:** `lead` 확인 사항(`MSG-0015`) 및 `docs/dev-setup.md` 5절(`server/app/main.py` 구현 기준). 출시 전 운영 주체 및 외부 AI API 프로바이더 확정 시 `[미정]`·`[확인 필요]` 항목만 채워 게시합니다.

### SaLLiM(살림) 개인정보처리방침 (초안)

**시행일:** `[확인 필요 — 정식 출시일 표기, 예: 2026년 11월 8일]`

`[확인 필요 — 운영 주체/팀명]`(이하 "서비스")은 이용자의 개인정보를 소중하게 생각하며, 「개인정보 보호법」 등 관련 법령을 준수합니다. SaLLiM은 별도의 회원가입이나 로그인 없이 이용할 수 있도록 설계되었습니다.

#### 1. 수집·처리하는 정보 및 이용 목적
1. **회원가입 및 계정 정보 없음**
   - 서비스는 회원가입, 로그인 기능을 두지 않으며 이용자의 이름, 전화번호, 이메일, 상세 집 주소 등 개인식별정보를 수집하지 않습니다.
2. **위치 정보(GPS) 미수집**
   - 서비스는 기기의 위치 권한(GPS)을 요청하거나 수집하지 않습니다. 배출 요일 안내를 위한 동네(`region_id`, 예: 시·구 단위)는 이용자가 화면에서 직접 선택합니다.
3. **기기 내부 저장 정보 (`AsyncStorage`) 및 동네 ID 전송**
   - 이용자가 선택한 동네 ID(`region_id`), 온보딩 완료 여부, 화면 모드(밝은/어두운 화면) 설정, 최근 확인한 품목 기록(최대 3개)은 이용자의 스마트폰 기기 내부 저장소(`AsyncStorage`)에 저장됩니다.
   - 동네 ID(`region_id`)는 동네별 배출 안내를 받기 위해 요청(`/ask`, `/schedule`)할 때 서버로 함께 보내지만 서버에 저장하지 않습니다. 나머지 항목(온보딩 완료 여부, 화면 모드, 최근 확인한 품목)은 기기에만 저장되며 서버로 보내지 않습니다.
4. **품목 확인을 위한 사진 데이터 (`image_base64`) 및 텍스트 질문 (`question`)**
   - **처리 목적:** 이용자가 촬영하거나 앨범에서 선택한 물건 사진 및 텍스트 질문은 분리배출 품목(`item_key`)과 상태(`ItemState`)를 판별하여 배출 방법을 안내하기 위한 목적으로만 일시 처리됩니다.
   - **전송 규격:** 앱에서 긴 변 1024px 이하의 JPEG 이미지(서버 수신 한도 최대 3MB)로 축소하여 전송합니다.

#### 2. 사진 데이터의 보관 및 파기 (서버 미저장 원칙)
- `/ask` 요청으로 전송된 사진 데이터(`image_base64`)는 서버가 요청을 처리하는 동안 **서버 메모리(RAM)에서만 일시적으로 사용되며, 서버의 디스크(파일 시스템), 데이터베이스(DB), 애플리케이션 로그에 저장하지 않습니다.**
- 요청 처리가 끝나면 더 이상 보관하지 않습니다.
- 이용자는 촬영 시 얼굴, 성명, 상세 주소, 전화번호 등 개인정보가 찍히지 않도록 주의해 주세요.

#### 3. 개인정보 처리의 위탁 (외부 AI 분석 서비스 전송)
- 개발·테스트 환경(`Mock` 프로바이더)에서는 사진과 질문 데이터가 서버 외부로 전송되지 않습니다.
- 실제 품목 인식 서비스를 운영하는 환경에서는 사진 내 물건 분류를 위해 아래와 같이 외부 AI 분석 서비스 API로 이미지·질문 데이터가 전송될 수 있습니다.
  - **수탁업체(제공받는 자):** `[미정 — 출시 시 사용하는 프로바이더 확정 표기: Anthropic PBC (Claude API) 또는 Google LLC (Gemini API)]`
  - **위탁하는 업무의 내용:** 촬영 사진 및 텍스트 질문 기반 분리배출 품목·상태 분류
  - **이전되는 항목:** 이용자가 전송한 물건 사진(base64 인코딩 이미지) 또는 텍스트 질문 문자열 (계정·기기 식별자 미포함)
  - **수탁업체의 보유 및 이용 기간:** `[확인 필요 — 출시 시 확정된 AI API 제공사의 기업용 API 데이터 비학습·보관 기간 정책 확인 후 기재]`

#### 4. 스마트폰 앱 접근 권한 안내
서비스는 필요한 범위에서만 선택적 접근 권한을 요청하며, 권한을 허용하지 않아도 이름 검색 및 배출 일정 확인 기능을 이용할 수 있습니다.
- **카메라 (선택):** 버릴 물건을 직접 촬영하여 분리배출 방법을 확인하기 위해 사용합니다.
- **사진 및 미디어/앨범 (선택):** 기기 앨범에 저장된 물건 사진을 불러와 분리배출 방법을 확인하기 위해 사용합니다.
- **위치 권한:** 요청하지 않습니다.

#### 5. 서버 접속 로그 및 보안에 관한 사항
- 애플리케이션 코드(`server/app/main.py`)는 이용자의 사진이나 질문 원문을 별도 DB·파일에 기록하지 않습니다.
- 단, 실제 배포 서버·클라우드 인프라의 기본 네트워크 접속 로그(접속 일시, IP 주소, HTTP 상태 코드 등) 수집 여부 및 보관 기간은 `[확인 필요 — 실제 서버 배포 환경 확정 후 기재]` 기준을 따릅니다.
