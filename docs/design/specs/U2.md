# U2 · 온보딩 3장 + 동네 선택

확정: A 살림 노트 · 390×844 · [U1 공통](../components.md) / [토큰 v2](../tokens.json). 문구는 `docs/research/ux-copy.md` 최종 키/원문 우선. 아래 키와 문구는 연결 전 기본값이다.

## 흐름·레이아웃

첫 실행: 온보딩1→2→3→동네 선택→홈. 다음 실행은 저장한 지역이 여전히 지원되는지 확인한 후 홈. 카메라 권한은 온보딩에서 요청하지 않는다. 동네를 고르기 전 지역 의존 요청을 시작하지 않는다.

390폭, safeTop30/Bottom20은 캡처 기준. 배경 colors.bg, 페이지 x20(space.page), 본문350. 상단 header64에 SaLLiM 좌측, “건너뛰기” 우측48 터치. 건너뛰기는 동네 선택으로 이동하며 임의 지역 확정 금지. 중앙 artwork350×240(sizes.onboardingArtHeight), 위 gap.space.xl32. 하단 제목 typography.heading32/40 최대3줄 허용, 설명 body16/24, 간격.md16. 제목과 설명 사이.smPlus12. 장식 SVG를 읽기에서 제외한다.

하단 dots3개는 장식으로 표시하고 접근성에는 “3장 중 1장” 문구를 제공한다. dot 기본 divider, 현재 primary, 간격.sm8. CTA는 본문폭350×최소52, radius.button, 마지막 gap.md16+safeBottom. 제목이 길거나 글자가 커지면 중앙 영역 스크롤, CTA가 설명을 덮지 않는다. 스와이프 외에도 “다음” 버튼으로 모든 장 이동 가능. 2·3장은 “이전”48 터치 제공.

| 장 | 키·제목 기본값 | 설명 기본값 | 직접 그릴 도형 / CTA |

| 1 | onboarding.photo.title · 찍으면, 버리는 법이 보여요 | onboarding.photo.body · 물건을 찍고 알맞은 배출 방법을 확인해요. | 병+프레이밍 모서리 / common.next · 다음 |
| 2 | onboarding.method.title · 순서대로, 간단하게 | onboarding.method.body · 비우고, 헹구고, 분리하는 순서를 한눈에 봐요. | 번호3개+안내장 / common.next |
| 3 | onboarding.region.title · 우리 동네 기준으로 | onboarding.region.body · 사는 동네에 맞는 배출 요일을 확인해요. | 집+요일 칩 / onboarding.start · 동네 선택하기 |

D3 파일 예정: `app/assets/brand/onboarding-photo.svg`, `onboarding-method.svg`, `onboarding-region.svg`. 없어도 빈 화면 대신 tint 도형 면을 유지한다. 브랜드 캐릭터·채팅 말풍선 없음.

## 동네 선택

header64: 뒤로48 + “사는 동네 선택”. main x20, 제목28/36(resultTitle) “사는 동네에 맞게 알려 드릴게요”(region.title). 본문 “같은 물건도 배출일은 다르니까요.”(region.description), gap.md16. 선택 입력은 label14/20+gap.sm8+min52, surface/text/border. 지원 지역은 API의 이름 그대로 표시한다.

목록행350×최소80, padding.md16, gap.smPlus12, radius.md. 미선택 surface/border1. 선택 tint/primary 선2+체크24+“선택한 동네”. 행 전체48 이상 터치, radio/selected 상태. 로컬 선택만으로 저장하지 않는다. 도움말 “동·공동주택에 따라 기준이 다를 수 있어요. 상세 주소와 위치 권한은 받지 않아요.” caption12/18. CTA “이 동네로 시작하기”(region.confirm), 최소52, 하단고정 영역 안에서 safeBottom 포함. 목록은 CTA 위까지 스크롤한다.

## 상태

| 상태 | 온보딩 | 지역 선택 |
|---|---|---|
| 기본 | 해당 장 artwork·제목·다음 버튼 | API 목록, 선택 전 CTA disabledBg/disabledText+“동네를 선택해 주세요” |
| 눌림 | Button primaryPressed, scale0.98/100ms | 행 surfacePressed, 선택 선 유지. CTA 공통 눌림 |
| 비활성 | 전환 중 다음 중복 입력 차단 | 저장 중·목록 미수신·선택 없음 CTA 비활성, 이유 caption |
| 로딩 | 폰트 대기는 정적 mark, 실패면 fallback | 카드2행 skeleton, “지원 동네를 불러오고 있어요”, 재요청 중 중복 방지 |
| 오류 | 자산 실패는 도형/글자 유지 | errorBg/error 아이콘+“동네 목록을 불러오지 못했어요”, “다시 불러오기”52. 기존 선택이 있으면 보존 |
| 빈 목록 | 해당 없음 | EmptyState “아직 안내할 수 있는 동네가 없어요”(region.empty), “다시 불러오기”(region.retry). 가짜 관악구 선택 금지 |
| 저장 실패 | 해당 없음 | 선택·스크롤 유지, CTA 위 error 문구 “동네를 저장하지 못했어요. 다시 시도해 주세요.”. 홈 이동 금지 |

지역 저장 성공 후 온보딩 완료 플래그를 함께 확정한다. 목록 재조회에서 저장 지역이 사라지면 해당 사실과 재선택을 보여 준다.

## 모션·다크·접근성

장 전환200ms motion.easing.standard([0.2,0,0,1]), opacity+X16 이동. 뒤로는 반대방향. 지역행 선택100ms, CTA light 햅틱, 장 넘김에는 강한 햅틱 없음. reduced motion은 이동0ms, 최종 상태만 표시. 전환 중 자동 넘김·카운트다운 없음.

다크: bg #15231C, surface #1F3027, text #F3F4E9, subtext #BECBBC, primary #ACD1B2, onPrimary #183323, tint #304838, errorBg #482C2A/error #FFBAB0. 모두 `themes.dark.colors` 의미 토큰으로 조회. 도형의 paper/ink/peach는 bg/text/accent 의미에 연결한다. 버튼과 선택행은 U1의 다크 상태 그대로.

스크린리더는 현재 장 제목으로 포커스, dots 반복 읽기 금지. 목록 radio label에 전체 지역명 포함. 200% 글자/320폭에서 제목·설명·행이 잘리지 않고 세로 스크롤. 성공한 선택만 가벼운 haptic1회. QA: 최초실행·재실행·건너뛰기·지역[]·오류·저장실패·긴 지역명·다크.
