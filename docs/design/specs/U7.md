## 공통 상태 프레임

일반 화면: safeTop30+header64, x.space.page20→350폭, 상단.md16, 탭70+safeBottom20. 카메라 처리중은 U4 프레임. 상태카드350, padding.lg24, radius.md20, surface/divider1. icon48, 제목 resultTitle28/36, gap.md16, 본문 body16/24, 보조caption12/18, CTA들 최소52·gap.smPlus12. 카드 높이는 내용에 따라 증가. 주요 상태문구를 장식 그림 아래 깊이 묻지 않는다.

모든 상태는 icon+제목+설명+다음 행동, 색만으로 구별 금지. 긴문구/200%글자/320폭에서 자르지 않고 main 스크롤. 입력·지역·사진은 재시도에 필요한 만큼 유지하고 다른 품목의 과거 결과를 새 결과처럼 표시하지 않는다.

## 기본·눌림·비활성·로딩·오류의 복구

복구 버튼 기본 primary/onPrimary 또는 secondary(surface/text/border). 눌림 primaryPressed/surfacePressed,100ms scale0.98. 비활성 disabledBg/disabledText opacity1, 중복요청 차단. 재시도중 클릭한 버튼은 busy+“다시 확인 중이에요”, 나머지는 입력취소/수정 가능 여부를 명확히 한다. 로딩은 기존 같은 품목의 확정 결과를 모두 skeleton으로 지우지 않는다. followup 오류는 Sheet 내 인접오류로 한정하고 기존 결과·선택답 유지. 재시도마저 오류면 같은위치에 문구 갱신, toast로만 알리지 않음.

취소·화면이동 후 응답은 현재요청이 아니면 무시. 실패 후 자동으로 계속 요청하지 않음. 재시도 입력 원문/boolean false 보존, 지역이 바뀌면 이전지역 응답 재사용 금지. 사용자취소는 빨간오류를 만들지 않는다.
