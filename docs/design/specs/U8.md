# U8 · 손맛 / 화면 전환 / 테마 전환

A 살림 노트 · 390×844 · [U1](../components.md) / [토큰](../tokens.json). 기능을 기다리게 하지 않는 짧은 피드백이 원칙. 화면 치수는 U2~U7 및 U9, 여기서는 상태전환 계약을 고정한다.

## 화면 구조·레이아웃

일반프레임은 safeTop30+header64, x.space.page20·폭350, 탭70+safeBottom20. 모션 중에도 터치영역과 safe area는 최종 레이아웃 기준으로 유지한다. absolute 레이어가 버튼을 가로막거나 전환 후 남지 않는다. Sheet390폭·최대85%높이, 안쪽350, top radius.lg28. 카메라는 전체화면 U4.

haptic: primary CTA light, capture medium, 예/아니오·요일선택 selection, 오류최초 notification-error-once. 같은버튼 길게누름/재렌더/비활성/자동로딩은 추가진동 없음. 웹·기기미지원은 조용히 fallback. haptic이 보이는 피드백을 대신하지 않음.

## 상태별 처리

| 상태 | 기대 |
|---|---|
| 기본 | 테마별 색·정적 최종배치. 이전 애니메이션의 scale/opacity가 남지 않음 |
| 눌림 | 100ms 피드백, press취소/화면이동 후복원. 빠른두번 클릭은 요청1개 |
| 비활성 | disabledBg/disabledText, opacity1, scale/haptic/이벤트 없음. 사유caption |
| 로딩 | busy 버튼+텍스트, skeleton/scan만반복. 응답도착즉시 종료, 남은애니메이션 대기 금지 |
| 오류 | errorBg/error+아이콘/설명, error haptic1회. 흔들기/계속진동 없음 |
| reduced motion | 모든위치/scale/반복 motion.reducedMotionMs0, 정적guide/skeleton+status 유지. 최종정보는 동일 |
| 앱 background→복귀 | 카메라 재준비/취소 요청상태 확인, 애니메이션 중복루프 생성 금지 |

설정의 테마 선택은 시스템/라이트/다크3개, 현재값과 체크를 표시한다. 시스템선택이면 기기 모드변화에 따라 같은 semantic 토큰을 조회한다. 선택값 저장실패는 U9의 인접오류, 기존 테마 유지 또는 롤백을 명시한다.

## 다크·접근성·검증

`themes.dark.colors`: bg #15231C/surface #1F3027/surfaceRaised #293E31/text #F3F4E9/subtext #BECBBC/primary #ACD1B2/onPrimary #183323/primaryPressed #91BC99/overlay #000000CC. 테마전환 중에도 전경·배경을 같은타이밍으로 전환한다. 각버튼·칩·경고·입력·시트·토스트 모두 같은테마를 사용한다.

390×844와320폭/200%글자에서 움직임 때문에 잘리거나 horizontal overflow가 생기지 않음. 스크린리더는 실제상태만 읽고 루프를 반복읽지 않음. 키보드포커스가 Sheet뒤로 빠지지 않음. 검증: 빠른탭/뒤로/닫기/취소→늦은응답, 화면전환중테마변경, reduced-motion, 웹햅틱fallback, background복귀. 실기기 haptic감도는 문서만으로 통과판정하지 않는다.
