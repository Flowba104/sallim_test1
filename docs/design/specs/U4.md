## 레이아웃·입력

기본 카메라는 전체화면, 하단 탭 숨김. 사진 프리뷰는 전체폭·전체높이 cover, 빈 프레임은 colors.cameraBg. safeTop30·safeBottom20은 캡처 기준, 실제 기기 inset 적용. 위64 영역에 닫기48(왼쪽20), 제목 “물건 찍기”(capture.header, section18/26), 반대편은 동일 폭 공백 또는 flash48. 기능 미지원 flash는 비활성 label과 함께 숨기거나 명시하며 작동하는 척 금지.

프레이밍 가이드 `sizes.cameraFrameWidth`286×`cameraFrameHeight`344, 390폭 중앙 x52. 가이드 모서리 border.selected2, radius.md20, onCamera. 가이드 위쪽 공간은 header 뒤32 이상, 하단에 안내 caption12/18 “재질 표시와 물건 전체가 보이게 놓아 주세요.”(capture.guide). 안내 뒤 cameraBg 면을 넣어 실제 카메라 이미지와 대비를 유지한다. 프레임은 촬영 강제 crop을 뜻하지 않으며 전체 사진을 전송할 수 있다.

아래 조작영역은 cameraBg, padding x20 / 위24 / 아래safeBottom+24. 촬영 버튼 `sizes.shutter`80×80 중앙, 외곽 onCamera3 / 간격8 / 안쪽64 원. 앨범 버튼52×52(surface/onPrimary가 아닌 onCamera 아이콘24+label12) 좌측, 우측 동일폭의 “한 번에 한 물건” 설명. 촬영 아래.smPlus12 “얼굴·주소가 함께 찍히지 않게 해 주세요.”(capture.privacy) caption. 앨범 취소는 촬영 화면 유지. 닫기는 이전화면으로 돌아감.

## 권한·사진 확인

카메라 권한 전: cameraBg가 아닌 colors.bg 기반 EmptyState(icon48, title28/36, body16/24), “사진으로 배출 방법을 확인해요”(capture.permission.title), “카메라 사용을 허용해 주세요.”(capture.permission.body), 주 CTA “카메라 허용”(capture.permission.allow), 보조 “앨범에서 선택”(capture.button.album). 시스템 권한창은 이 버튼의 명시적 행동 후. 거절 후 반복 시스템창 자동호출 금지. 영구거절은 “설정에서 카메라 허용”52와 앨범/이름입력48 선택 제공. 권한 진행 중 Button loading.

촬영/앨범 선택 직후 같은 프레임에 선택 사진을 고정하고 전송/분석 상태 표시. 사진을 다시 선택할 수 있는 취소 제공. 별도 강제 미리보기 확인단계를 추가해 3초 목표를 방해하지 않는다. 원본이 세로/가로여도 찌그러뜨리지 않고 cover, 회전방향은 이미지 메타데이터 기준 coder 처리.

## 모션·다크·접근성

셔터 입력 medium haptic1회, 분석 성공시 과도한 진동 없음. 스캔선1600ms 왕복, motion.easing.linear[0,0,1,1], 프레임 내부에서만 이동. 스켈레톤1200ms standard[0.2,0,0,1]. 결과 수신 즉시 스캔 중지, 카드260ms Y16→0 enter[0.16,1,0.3,1]. 화면200ms. reduced motion이면 스캔·반복·scale0ms, 정적 가이드와 “확인 중” 텍스트 유지.
