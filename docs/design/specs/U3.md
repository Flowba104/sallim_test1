## 데이터·상호작용

- today는 서버 값. 선택한 주간 요일과 분리한다. 요일 칩을 눌러도 “오늘” 카드와 서버 today를 변경하지 않는다. 선택 칩은 primary/onPrimary+selected, 실제 오늘은 “오늘”이라는 label/접근성 문구 추가.
- 320폭에서 요일을4+3행으로 바꾼다. 44보다 작아지게 압축하거나 겹치는 hitSlop 금지. 큰 글자에서도 요일 레이블 잘림 없음.
- 전체목록 Sheet는 title “오늘 배출할 수 있는 품목”, 카테고리 아이콘+원문 이름 모두 표시, min48행, 닫기48. U1 Sheet 규칙. 데이터에 없는 카테고리를 추가하지 않는다.
- 최근 질문은 로컬 실제 조회 결과만. 선택 시 저장된 지역과 현재 지역이 다르면 이전지역 표시 또는 현재지역 재조회. 오래된 결과를 오늘 답으로 조용히 덮어 쓰지 않는다. 최근 데이터 저장 정책은 coder/lead 결정, 존재하지 않는 샘플은 넣지 않는다.
- `today_categories=[]` → “안내할 품목이 없어요. 동네 안내를 확인해 주세요.”(home.today.empty). 자체 추론으로 “배출 금지” 금지. week의 빈 값도 동일. next-day 날짜·D-day 계산 없음.
