## 동네·테마 동작

동네변경은 기존지역 표시→선택→명시적 저장성공 후 반영, 실패시이전지역 유지. 변경완료 시 홈일정 재조회, 과거결과는 이전지역 표시 또는폐기/재조회. 현재지역과 다르게 저장된 질문을 새지역답으로 덮어쓰지 않는다. 변경해도 온보딩3장을 다시 보이지 않는다.

테마선택은 즉시화면전체에 반영하고 선택값 저장. 시스템선택이면 OS모드변화에 따름. 저장실패는 아래 인접error문구와 이전값롤백 또는 재저장을 명시해 UI와 저장값이 다르게 남지 않게 한다. 빠른전환 중마지막선택이최종값. 설정한 모드는 Sheet/Toast/키보드/탭/상태창에도일관 적용.
