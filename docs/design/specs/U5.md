## 신뢰와 데이터 누락

- `item_key=null` 또는 이름/카테고리가 없는 품목은 U7 unknown. 없는 품목에 임의 카테고리/요일 생성 금지.
- `confident=false`+품목 있음: “이 품목으로 보여요. 재질 표시를 확인해 주세요.” 경고와 “품목 후보” 표시. 사용자 확인 버튼만으로 true 바꾸지 않음. 일정 제목 앞에 “이 품목이 맞다면”을 유지한다.
- `next_days=[]`는 “배출 요일 확인 필요”, time=null은 “배출 시간 확인 필요”. 배열에서 실제 날짜·내일·D-day 추정 금지.
- note가 있으면 일정 바로 아래. 출처 접기 또는 tooltip 안으로 숨기지 않음. sources=[]는 “출처 확인이 필요해요”, 빈 아코디언 금지.
- updated의 label은 “자료 기준”. 출처가 공식 홈페이지 루트이면 세부 지침 링크인 것처럼 표현하지 않는다. 외부링크임을 icon+label로 알린다.
- steps=[]는 answer+일정 유지, 빈 체크리스트/임의3단계 생성 금지.
