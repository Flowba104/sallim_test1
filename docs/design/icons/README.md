# 카테고리 아이콘

[한눈에 보기](index.html) · [정확한 카테고리 대응](manifest.json)

12개 모두 직접 그린 단순 선형 SVG다. 외부 아이콘·캐릭터·브랜드 자산을 사용하지 않았다. 24×24 viewBox, 2px stroke, 둥근 끝·이음, fill=none, stroke=currentColor. 배경은 투명하다. 24 또는32 크기를 기본으로 사용한다.

카테고리 의미를 아이콘만으로 전달하지 않는다. 이름을 옆에 표시할 때 SVG는 장식으로 숨기고 Text가 카테고리를 읽게 한다. standalone SVG에는 한국어 title과 role=img가 포함돼 있다. RN SVG 컴포넌트로 옮길 때 title·aria-labelledby 처리는 플랫폼 방식에 맞추고 중복 ID를 만들지 않는다.

투명페트=짧은 목·요철, 유리병=긴 목·매끈한 몸체, 종이=한 장, 종이팩=접힌 지붕으로 구별한다. 음식물은 뼈·껍데기처럼 일반쓰레기인 예시를 피하고 그릇 형태를 쓴다. 전용수거는 수거함, 대형폐기물은 의자로 대표한다. 이 도형은 분류 자체를 결정하는 근거가 아니다.

색은 colors.primary 또는 colors.text. 카테고리별 서로 다른 색은 필수가 아니다. SVG만으로 터치 영역을 만들지 말고 조작인 경우 최소48px 컨테이너를 사용한다.
