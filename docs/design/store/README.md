# 플레이스토어 스크린샷 5장 시각 초안

[미리보기](index.html) · [순서·문구·UI 대응](manifest.json)

1080×1920 세로 캔버스 다섯 장. A 살림 노트의390×844 HTML UI를 확대 배치했다. 외부 사진·캐릭터·이미지를 사용하지 않았고, UI와 도형은 단일 HTML 안에 포함된다. PNG는 각 캔버스를 브라우저에서 렌더링한 결과다.

1. **찍어서 알아보기** — 촬영 UI. 품목 사진에서 시작하는 흐름.
2. **투명페트 배출 순서** — 결과 카드. 체크리스트·목요일·시간·출처.
3. **우리 동네 일정** — 홈. 오늘 품목·주간표·공동주택 예외.
4. **상태 되묻기** — 라벨 질문. 예·아니오로 추가 확인.
5. **텍스트 질문** — 품목 이름으로 찾는 흐름.

모든 장 상단에 “디자인 초안 · 화면 예시”를 넣었다. 실제 앱 캡처로 오해시키지 않는다. “3초 보장”, “정확도100%”, “모든 동네 지원”, 인식 성공률·수거 보장 표현은 쓰지 않았다. 첫 지역은 관악구이며 공동주택·가로지역 차이는 UI에 표시한다.

이 캔버스 크기는 디자인 제작 규격이다. 최종 스토어 등록 규격 검수나 게시를 수행한 것은 아니다. 오너가 방향을 고르고 실제 구현 화면·검증 데이터를 확인한 뒤 교체해 사용할 초안이다. 등록 파일 생성·앱 게시 작업은 범위에 없다.
