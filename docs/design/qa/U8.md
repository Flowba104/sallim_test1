1. **테마 선택** — “어두운 화면”은 실제 bg #15231C/text #F3F4E9, “밝은 화면”은 bg #F7F3E8/text #253D32로 화면 전체를 전환한다. `theme_pref` 저장 후 새로고침해도 선택색과 radio checked가 유지됐다. 양방향 assert 통과. 초기 Appearance 웹 제한은 coder의 useScheme 반영으로 해소됐으므로 지원제한 안내문은 필요하지 않다.
2. **접근성 상태** — 선택 radio는 aria-checked=true, 요일Chip은 aria-selected=true, 출처는 aria-expanded=false→true를 실제 DOM에서 확인했다. 시각적 선택의 tint/선2와 의미상태가 일치한다.
3. **모션·레이아웃** — `app/lib/usePressScale.ts`의100ms/standard/0.98·reduced-motion고정1, Sheet280/200ms, skeleton1200ms를 코드에서 확인했다. 기본캡처는 reduced-motion reduce. 탭바70px, 실제탭대상61px, label12/18 Pretendard-SemiBold 확인. viewport 가로overflow 없음, 페이지오류0.

네이티브60fps·햅틱강도·OS글자200%·TalkBack·하드웨어상태바는 미검증이다. 180ms테마색크로스페이드는 미구현(즉시색전환)으로 남아 있으며 최초 coder 보고의 작은 모션 차이로 기록한다. [초기 라이트 미전환 기록](U8-theme-selected-dark-from-light.png)은 수정 전 비교용이다.
