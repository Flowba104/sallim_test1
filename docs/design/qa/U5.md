1. **[우선] 물어보기→결과 / 첫스크롤 위치** — 현재 응답 후 `scrollToEnd()` 때문에 새결과의 최상단 Mock경고가 화면밖이고 카테고리헤더 상단도 잘려 보인다. 기대: U5결과 래퍼 시작점(경고포함)으로 이동한 뒤 결과제목에 접근성포커스. `space.md`16의 위여백과 `motion.cardEnterMs`260을 유지하고 입력/추천목록으로 다시 스크롤하지 않아도 예시/후보임을 먼저 읽게 한다. 잘못된 안내로 오인되는 위험이 있어 우선수정.
2. **되묻기 / 실패답 보존·재시도** — 코드상 `setState(next)`는 성공후에만 실행하고 오류시 선택답을 기억하는 별도상태가 없다. 기대: 선택한 true/false를 유지·표시하고 동일답 재시도52(`sizes.buttonMinHeight`) 제공. `result.followUp.error`를 질문옆 `colors.errorBg/error`로 표시하며 다른답으로 바꾸기 전까지 선택을 잃지 않음. 오류 fixture로 추가 확인 예정.

품목·카테고리색·번호3단계·요일/시간/note와 출처접기 확인. false 선택 후 Sheet닫힘은 양테마에서 성공. Sheet 긴질문/큰글자/12카테고리는 공통컴포넌트 수정후 추가 스트레스검증한다. 실제 followup 누적 요청본문은 fixture QA에서 확인한다.
