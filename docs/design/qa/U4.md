1. **[우선] 촬영 권한 화면 / 좌상단 닫기** — 현재 `colors.onCamera` #FFFFFF가 `colors.bg` #F7F3E8 위에 놓여 닫기×가 거의 안 보인다. 기대: 일반 권한프레임은 `colors.text` #253D32(다크 #F3F4E9), 실제 카메라 overlay만 onCamera. 닫기 터치 `sizes.touchMin`48 유지. icon 대비3:1 이상.
2. **촬영 결과 / 탐색 복귀** — 코드상 capture 탭전체의 tabBarStyle display:none이고 result 분기에도 header/Close가 없다. 기대: U4 전체화면촬영에서만 탭숨김, U5결과에서는 결과헤더·동네·이전행동 또는 선택된찍기탭을 복원(`sizes.headerMinHeight`64/`tabBarMinHeight`70). 실제 결과에서 홈/설정으로 이동할 경로가 첫부분에 있어야 한다. 웹 카메라결과는 추가 fixture에서 재현할 예정으로 현재는 코드근거다.
