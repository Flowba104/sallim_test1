# 앱 아이콘·스플래시 초안

추천 A 살림 노트 기준. [미리보기](index.html).

- `app-icon.svg` / `app-icon.png`: 1024×1024 마스터, 숲색 불투명 배경. 앱 이름 글자를 작게 넣지 않고 직접 그린 접힌 안내장+세 줄을 사용.
- `mark.svg` / `mark.png`: 배경 없는 벡터 심볼. 마스터와 같은 좌표계.
- `splash.png`: 390×844 시각 초안. 중앙 심볼·SaLLiM·슬로건, 하단 작은 브랜드 문구. 인식 처리 중 로딩 화면과 구별하며 진행률·강제 대기 문구를 넣지 않음.
- `icon-sizes.png`: 180/80/48px 아이콘과 스플래시 비교 화면.

기존 브랜드·캐릭터·스톡 이미지를 사용하지 않았다. 워드마크는 Pretendard/시스템폰트로 표기하며 최종 커스텀 로고 확정본이 아니다. 심볼 사방에 최소 심볼 폭의1/4 여백을 유지한다. 접힘 색면을 삭제·패턴화하거나 심볼에 다른 카테고리 표시를 덧붙이지 않는다.

PNG는 SVG/HTML을 브라우저에서 렌더링한 결과다. 앱아이콘 등록이나 Expo 설정 파일 변경은 하지 않았다. 플랫폼별 안전영역·adaptive icon·시스템 스플래시 동작은 실제 앱에 적용할 때 별도 확인한다. 앱 마스터 파일은 라운드 모서리를 굽지 않은 정사각형이며 미리보기의 둥근 모서리는 CSS 마스크다.
