# 추천안 확장 화면

human MSG-0021의 2차 범위. [화면 5개](index.html)

- 온보딩3장: 품목 촬영 → 순서 안내 → 우리 동네 일정. 각 단계 건너뛰기 가능, 가입이나 위치 권한 없이 동네 선택으로 연결.
- 설정: 저장된 지역 변경, 자료 출처, 앱 소개. mock 상태를 실제 안내와 구분. 지원하지 않는 알림·계정 기능을 추가하지 않음.
- 빈 배출 안내: region_id는 있지만 ScheduleResponse의 today_categories/week/time/sources가 비어 있는 경우. 요일·시간을 만들거나 휴일·배출금지라고 단정하지 않음. 목록 자체가 빈 경우는 기존 states의 empty-region 화면.

캘린더 예시는 관악구 투명페트 목요일18~24시. 실제 화면은 API값을 사용하고 note 예외를 표시한다. 온보딩 진행 상태 영구저장 여부는 이번 디자인 초안에서 구현하지 않는다. 버튼은 파일 내·외 데모 링크이며 요청 재시도는 예시 메시지다.
