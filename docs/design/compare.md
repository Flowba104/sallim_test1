# 네 방향 비교와 추천

**추천: A · 살림 노트 (`warm-note`)**. 집 안의 생활 안내장처럼 읽히는 세로 구성으로 품목·배출 순서·다음 요일이 연결된다. 색을 줄이고 얇은 선과 여백으로 구분해 작은 Android 화면에서도 결과를 차분하게 읽을 수 있다. 이는 디자이너의 판단이며 사용자 선호도나 수행 시간 실험의 결과는 아니다. MISSION v2의 `추천안`과 lead MSG-0003(2026-11-06)에 따라 이번 구현은 A로 확정한다.

## A를 추천하는 이유

1. “찍으면 어떻게 버리는지 알 수 있다”는 경험을 체크리스트와 일정 카드가 직접 설명한다. 사진보다 결과가 중심이고, 대화 말풍선이 필요 없다.
2. 자취생에게 친숙한 생활 안내장 톤을 유지하면서 경고·출처·동네 예외도 같은 읽기 흐름에 담을 수 있다. 확신 낮음은 색보다 문장과 아이콘으로 드러낸다.
3. 구현에 필요한 고유 자산이 12개 카테고리 아이콘과 소수 도형으로 한정된다. 반경·여백·숫자 토큰으로 React Native에 옮기기 쉽다.
4. 네 안 모두 필수 정보와 대비 기준을 만족한다. 그중 A는 장식과 정보 밀도의 균형을 위해 그림·큰 제목·진한 면에 대한 의존이 가장 적다.

## 추천안 적용 때 지킬 것

- 종이 질감 이미지·테이프 장식은 추가하지 않는다. 홈 안내장의 작은 색면 한 곳으로 생활감을 표현한다.
- 결과 제목은 28px, 본문 16px을 유지하고 긴 품목명은 두 줄로 허용한다. 배출 절차를 자르지 않는다.
- `next_days`는 **다음 배출 요일**로 부른다. API가 날짜를 주지 않으므로 “내일”, “D-1”, 특정 날짜를 계산해서 붙이지 않는다.
- `note`는 결과 일정 바로 아래, 홈 주간 표 아래에 표시한다. `updated`는 **자료 기준**으로 표기한다. 실제 확인 날짜와 혼동하지 않는다.
- 관악구 자료는 단독주택·상가 기준이며 공동주택·가로지역 예외가 있다. 공식 홈페이지 링크와 세부 URL 미확보 상태를 출처 상세에 명시한다.
- D6 토큰은 A를 기준으로 제공한다. MISSION v2에서 추천안 채택, v2 토큰은 라이트·다크 및 U1 공통 상태를 포함한다.

## 아직 검증하지 않은 것

실사용자의 3초 내 이해, 실제 인식 속도·정확도, Android 기기 큰 글자·TalkBack, 앱 카메라 동작. HTML의 선택·재시도는 디자인 데모다. 상세 검증 범위는 verification.md에 기록했다.
